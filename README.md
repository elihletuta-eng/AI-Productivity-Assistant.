# CAPACITI Workflow AI – Workplace Productivity Assistant

## Project Overview

CAPACITI Workflow AI is an AI-powered workplace productivity platform designed to help employees and employers work smarter, communicate effectively, manage tasks efficiently, and improve workplace collaboration.

The platform uses Artificial Intelligence to automate repetitive workplace activities such as email writing, meeting summarization, task planning, research assistance, and productivity coaching. The goal is to save time, improve productivity, and create a better work environment through responsible AI usage.

## Installation

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project Folder

```bash
cd capaciti-workflow-ai
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Responsible AI Statement

This platform follows responsible AI principles:

- AI-generated content may contain inaccuracies.
- Users should verify important information before acting on it.
- AI outputs are suggestions and should not replace professional judgment.
- Users should not enter confidential, sensitive, or private workplace information.
- Human review is recommended for all critical decisions.

## Innovation

The platform introduces an **AI Productivity Coach** that analyzes user activities and provides personalized recommendations to improve productivity, time management, communication, and workplace efficiency.
